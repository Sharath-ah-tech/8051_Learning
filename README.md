
# 8051 LED ON/OFF

## Objective
To learn basic 8051 I/O port programming using Embedded C.

## Tools Used
- Keil uVision
- Proteus Design Suite
- 8051 Microcontroller

## Program Description
The program changes Port 2 output between HIGH and LOW
states with a delay, creating a repeating LED ON/OFF pattern.

## Files
- `LED_ON_OFF.c` - Embedded C source code
- `LED_ON_OFF.pdsprj` - Proteus simulation project
